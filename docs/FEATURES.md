# ReStory Repair Workspace — feature reference

Project records, reference groups, and workspace notes form the core of ReStory Repair Workspace. Related configuration is grouped by task rather than collected in an undifferentiated list.

| Section | Description |
|---|---|
| Project records | A dedicated section for project records and the configuration details associated with that area. |
| Reference groups | A dedicated section for reference groups and the configuration details associated with that area. |
| Workspace notes | A dedicated section for workspace notes and the configuration details associated with that area. |

The project page follows the same section structure.
